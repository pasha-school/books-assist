# AGENTS.md

Входная точка для AI-агента, который помогает разбирать художественные произведения по мере чтения вместе с ребёнком.

> Этот файл — главный. Перед любым действием прочитай его целиком, затем — нужные правила из [`_agents/rules/`](_agents/rules/) и навык из [`_agents/skills/`](_agents/skills/).

## Миссия

Превращать прочитанные главы в **инкрементальный граф знаний** в Obsidian: персонажи, места, события и связи между ними. Граф должен:

- расти **по главам**, без спойлеров из непрочитанного;
- быть **редактируемым человеком** (ребёнок и взрослый могут дополнять заметки);
- быть **машиночитаемым** (frontmatter + Dataview inline-поля; граф визуализируется в Obsidian через плагин [Extended Graph](https://github.com/ElsaTam/obsidian-extended-graph)).

## Базовая онтология (5 типов заметок)

| Тип | Папка | Шаблон |
|---|---|---|
| `book` | `Книги/<Название>/index.md` | [`_agents/templates/book-index.md`](_agents/templates/book-index.md) |
| `chapter` | `Книги/<Название>/Главы/` | [`_agents/templates/chapter.md`](_agents/templates/chapter.md) |
| `character` | `Книги/<Название>/Персонажи/` | [`_agents/templates/character.md`](_agents/templates/character.md) |
| `location` | `Книги/<Название>/Места/` | [`_agents/templates/location.md`](_agents/templates/location.md) |
| `event` | `Книги/<Название>/События/` | [`_agents/templates/event.md`](_agents/templates/event.md) |

Опционально:
- `concept` (предметы, идеи, явления) — [`_agents/templates/concept.md`](_agents/templates/concept.md)
- `_исходный текст` — директория для хранения оригинального текста книги по главам

**Ключевое:** `event` связывает `character` и `location` — это центральный связующий узел графа.

## Жёсткие правила (нарушать нельзя)

См. [`_agents/rules/`](_agents/rules/). Кратко:

1. **Никаких спойлеров** из глав, которые ребёнок ещё не прочёл — [`no-spoilers.md`](_agents/rules/no-spoilers.md).
2. **Инкрементальность**: создавай **только новые** сущности; для существующих — дописывай, не перезаписывай — [`incremental-updates.md`](_agents/rules/incremental-updates.md).
3. **Схема frontmatter фиксирована** — не вводи новые поля без явного запроса — [`schema.md`](_agents/rules/schema.md).
4. **Нейминг файлов** — кириллица, имена как в книге, без транслита — [`naming.md`](_agents/rules/naming.md).
5. **Связь = факт из текста**, а не догадка. Если не уверен — пометь `confidence: low` — [`evidence.md`](_agents/rules/evidence.md).

## Контракт ответа агента

Когда агент разобрал главу, он должен вернуть:

1. Список созданных/обновлённых файлов (путь + краткое «что изменилось»).
2. Изменения, потребовавшие внимания человека (например, спорная связь — помечена `confidence: low`).
3. **Не** показывать сырой JSON и не «пересказывать главу» в чате — вся информация уходит в заметки.

## Стек плагинов, на который рассчитан агент

- **Dataview** — для запросов и inline-полей `ключ :: значение`.
- **Extended Graph** — для интерактивного графа знаний поверх стандартного Graph View (типы узлов и рёбер берутся из frontmatter/тегов).
- **Templater** *(опционально)* — для удобного создания заметок руками.

Если плагина нет — агент всё равно пишет данные в frontmatter, граф строится позже.

**Важно:** Это проект для Obsidian. Ошибки валидации от других инструментов (например, Diplodoc) можно игнорировать — главное, чтобы структура работала в Obsidian.
