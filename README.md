# Reader's Vault

Obsidian-хранилище для совместного чтения книг с ребёнком и инкрементального построения графа знаний (персонажи, места, события, связи) силами AI-агента.

## Идея

После каждой прочитанной главы AI-агент:

1. Извлекает из текста главы **новые** сущности и связи (без спойлеров).
2. Создаёт или обновляет заметки по строгим [шаблонам](_agents/templates/).
3. Дополняет `relations` в frontmatter персонажей (плагин Extended Graph рисует граф по типам узлов и связей).
4. (Опционально) генерирует `.canvas` — «карту главы» для просмотра вместе с ребёнком.

## Структура

```
obsidian_vault/
├── AGENTS.md                ← правила для AI-агента (читается в первую очередь)
├── _agents/
│   ├── rules/               ← инварианты: схема, нейминг, инкрементальность
│   ├── skills/              ← навыки: extractor, relation-mapper, canvas-builder, spoiler-guard
│   ├── prompts/             ← готовые промпты
│   └── templates/           ← шаблоны заметок (character/location/event/chapter/...)
└── Книги/
    └── <Название книги>/
        ├── index.md
        ├── Главы/
        ├── Персонажи/
        ├── Места/
        ├── События/
        └── Понятия/
```

## Обязательные плагины Obsidian

- **Dataview** — запросы по frontmatter (списки персонажей главы, связей и т.п.).
- **Extended Graph** — расширение стандартного Graph View: фильтры по типам и тегам, подписи рёбер из frontmatter.
- **Templater** — подстановка шаблонов при создании заметок.
- **Excalidraw** *(опционально)* — рукописные схемы вместе с ребёнком.

Рекомендуемый LLM-плагин (любой на выбор): **Smart Composer**, **Copilot for Obsidian**, **Text Generator**.

## Как начать новую книгу

1. Скопировать [`_agents/templates/book-index.md`](_agents/templates/book-index.md) в `Книги/<Название>/index.md`.
2. Создать пустые подпапки `Главы/`, `Персонажи/`, `Места/`, `События/`, `Понятия/`.
3. После каждой главы — запустить промпт [`_agents/prompts/extract-chapter.md`](_agents/prompts/extract-chapter.md).
