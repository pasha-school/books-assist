# Prompt: bootstrap-book

Промпт для инициализации новой книги.

## Промпт

```
Ты — ассистент по моему Obsidian-хранилищу. Активный навык — `_agents/skills/bootstrap-book.md`.

Создай скелет новой книги:
- Название: <Название>
- Автор: <Автор>
- Папка (опционально): <slug, или оставь пустым>

Действия:
1. Проверь, что папка Книги/<slug>/ ещё не существует.
2. Создай папки: Главы/, Персонажи/, Места/, События/, Понятия/.
3. Создай index.md по шаблону _agents/templates/book-index.md с:
   - title, author из ввода
   - read_through: 0
   - started_on: сегодня (YYYY-MM-DD)
4. Сообщи путь к созданному index.md и подскажи, что дальше — навык extract-chapter.
```

## Когда применять

- Один раз на книгу, перед первой главой.
- При параллельном чтении нескольких книг — отдельный запуск на каждую.
