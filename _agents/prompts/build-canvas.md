# Prompt: build-canvas

Промпт для генерации `.canvas`-карты главы или книги.

## Промпт

```
Ты — ассистент по моему Obsidian-хранилищу. Активный навык — `_agents/skills/canvas-builder.md`.

Контекст:
- Книга: <Название>
- Папка: Книги/<slug>/
- Область карты: <chapter N | book>
- Если карта главы — номер главы: <N>

Что сделать:

1. Собери список узлов:
   - персонажи, появляющиеся в этой главе (или все, если карта книги);
   - места этой главы (для книги — все);
   - события главы (для книги — НЕ включать события);
2. Собери рёбра:
   - все relations персонажей из их frontmatter (label = type);
   - персонаж—событие через participants (label = "участвует");
   - событие—место через location (label = "место").
3. Раскладка — кластерная: персонажи слева, места справа, события снизу. Сетка 300×180.
4. ID узлов и рёбер — детерминированные (см. правила в skill).
5. Если `Книги/<slug>/Главы/Глава-NN.canvas` или `Книги/<slug>/Карта.canvas` уже есть — сохрани координаты существующих узлов по id.

Выход — содержимое .canvas файла (валидный JSON по spec jsoncanvas.org/spec/1.0/) и путь, куда его сохранить.

После — короткий отчёт: путь, количество узлов, рёбер, сколько координат перенесено из старой версии.
```

## Когда применять вручную

- Раз в несколько глав — обновить «карту книги».
- После каждой важной главы — карту главы для совместного просмотра.
- Не нужно после каждой мелкой правки — `.canvas` это снимок, а живой граф смотрите в Obsidian Graph View с плагином Extended Graph.
