# Prompt: extract-chapter

Готовый промпт для копирования в LLM-плагин Obsidian (Smart Composer / Copilot for Obsidian / Text Generator).

## Как использовать

1. В Obsidian открой заметку главы или вставь текст главы в чат с LLM.
2. Скопируй блок ниже, замени плейсхолдеры `<...>` и отправь модели.
3. Модель вернёт список действий по vault — примени их (или плагин сделает это сам).

---

## Промпт

```
Ты — ассистент по чтению, работающий с моим Obsidian-хранилищем `obsidian_vault/`.

Главный документ с правилами — `AGENTS.md` (прочитай его и относящиеся к делу файлы из `_agents/`).
Сейчас активный навык — `_agents/skills/extract-chapter.md`. Следуй ему буквально.

Контекст:
- Книга: <Название>
- Папка книги: Книги/<slug>/
- Номер главы: <N>
- read_through до этого: <N-1> (или 0, если первая глава)

Ниже — ТЕКСТ ГЛАВЫ. Используй ТОЛЬКО его и существующие заметки vault.
Любые внешние знания о произведении (твоё «обучение») — запрещены как источник фактов.

<<<
<сюда вставить текст главы>
>>>

Что я хочу получить:

1. Список действий в формате:
   - CREATE <путь от корня vault>
     ```yaml
     <frontmatter>
     ```
     <тело заметки>
   - UPDATE <путь>
     <минимальный diff: что добавить, ничего не удаляй>

2. Отдельным блоком — список фактов с confidence: low, требующих моей проверки.

Не пересказывай главу в чате. Не показывай сырой JSON. Не ссылайся на будущие главы.
В конце увеличь read_through в index.md до <N>.
```

---

## Подсказки

- Если у вас короткие главы — можно подавать сразу две за один запрос, но укажите оба номера в `Номер главы`.
- Если LLM-плагин умеет писать файлы напрямую — попросите его «применить действия», иначе копируйте вручную.
- После применения проверьте `Книги/<Название>/index.md` — `read_through` должен обновиться.
