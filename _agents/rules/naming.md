# Rule: naming

Имя файла = идентификатор узла в графе. От его стабильности зависит вся сеть ссылок.

## Общие правила

- **Кириллица как в книге.** Никакого транслита: `Алиса.md`, не `Alisa.md`.
- Без расширения в ссылках: `[[Алиса]]`, а не `[[Алиса.md]]`.
- Пробелы разрешены, кавычки — нет.
- Запрещённые символы в имени файла: `\ / : * ? " < > |`. Заменяй на `-`.

## Шаблоны имён по типам

| Тип | Шаблон | Пример |
|---|---|---|
| `book` (index.md) | `index.md` в папке `Книги/<Название>/` | `Книги/Алиса в стране чудес/index.md` |
| `chapter` | `Глава-NN.md` (двузначный номер с ведущим нулём) | `Глава-01.md`, `Глава-12.md` |
| `character` | `<Имя как в книге>.md` | `Алиса.md`, `Белый Кролик.md` |
| `location` | `<Название как в книге>.md` | `Кроличья нора.md` |
| `event` | `E<NNN>-<краткий-кебаб>.md` | `E003-падение-в-нору.md` |
| `concept` | `<Термин>.md` | `Часы Кролика.md` |

## Имена персонажей: приоритет полного имени

- Используй наиболее полное **называние, встреченное к этому моменту в книге**.
- Прозвища → в `aliases`, не в имя файла.
- Если позже книга раскрывает полное имя (например, был «Старик», стал «Сантьяго») — **не переименовывай файл**, добавь новое имя в `aliases`, оставь файл `Старик.md`. Перенаименование сломает все ссылки.

## Разрешение конфликтов имён

Если в одной книге два персонажа с одинаковым именем:

- Добавь уточнение в скобках: `Иван (садовник).md` vs `Иван (король).md`.
- В `aliases` укажи короткое имя.
- Это **исключение**, в остальных случаях скобки не используй.

## Папки книги

```
Книги/<Название книги>/
  ├── index.md                  ← book
  ├── Главы/Глава-01.md         ← chapter
  ├── Персонажи/<Имя>.md        ← character
  ├── Места/<Место>.md          ← location
  ├── События/E001-…md          ← event
  └── Понятия/<термин>.md       ← concept (опционально)
```

Папки создаются **только при первом появлении** сущности соответствующего типа.
