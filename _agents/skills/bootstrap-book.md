# Skill: bootstrap-book

Создание скелета новой книги в vault.

## Когда применять

- Пользователь говорит: «Начинаем читать <Название> <Автора>».
- Перед первым запуском [`extract-chapter`](extract-chapter.md) для новой книги.

## Вход

- `title` — название книги.
- `author` — автор.
- (опционально) `slug_folder` — имя папки. По умолчанию = `title` с заменой запрещённых символов (см. [`../rules/naming.md`](../rules/naming.md)).

## Алгоритм

### Шаг 1. Проверь, что книги ещё нет

Папка `Книги/<slug_folder>/` не должна существовать. Если существует — **остановись** и сообщи пользователю; не перезаписывай.

### Шаг 2. Создай структуру

```
Книги/<slug_folder>/
├── index.md          ← по [`../templates/book-index.md`](../templates/book-index.md)
├── Главы/            ← пусто
├── Персонажи/        ← пусто
├── Места/            ← пусто
├── События/          ← пусто
└── Понятия/          ← пусто (создаём впрок, если не пригодится — не страшно)
```

### Шаг 3. Заполни `index.md`

Используй шаблон [`../templates/book-index.md`](../templates/book-index.md). Заполни:

- `title`, `author` — из ввода;
- `read_through: 0` — ничего ещё не прочитано;
- `started_on: <YYYY-MM-DD>` — сегодня;
- `finished_on: null`.

Если есть подзаголовок, переводчик, год — можно добавить в тело заметки текстом, **но** не в frontmatter (схема фиксирована).

### Шаг 4. Отчёт

Сообщи пользователю:

1. Где находится `index.md` (полный путь).
2. Что нужно делать дальше: «Прочитайте главу 1 и попросите меня запустить навык `extract-chapter`».
3. Перечень обязательных плагинов из [`../../README.md`](../../README.md).

## Антипаттерны

- ❌ Создавать заметки персонажей/мест на этом шаге (мы их ещё не знаем).
- ❌ Заполнять `read_through` числом > 0 «авансом».
- ❌ Дублировать книгу, если она уже есть с другим написанием — лучше спросить.
