# Псарный двор Троекурова

## Описание

Великолепная псарня Кирилы Петровича Троекурова, предмет его гордости. Содержит более 500 гончих и борзых собак, имеет лазарет для больных собак и отделение для щенков.

## Характеристика

- **Владелец**: [[Кирила Петрович Троекуров]]
- **Размер**: Более 500 собак
- **Особенности**: Лазарет для больных собак, отделение для щенков
- **Значение**: Символ богатства Троекурова, место начала конфликта с Дубровским
